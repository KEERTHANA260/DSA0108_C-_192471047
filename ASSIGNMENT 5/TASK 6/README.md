# Task06 B1 Polymorphic Billing

Implements all bill and payer types and verifies hand-calculated totals.

## Compile and run
```bash
g++ -std=c++17 -Wall -Wextra -O2 code.cpp -o app
./app
```

See `output.txt` for the captured output and `screenshots/output.png` for its image. Design tasks also include `design.md`.
