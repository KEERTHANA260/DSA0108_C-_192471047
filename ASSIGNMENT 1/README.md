# Assignment 1 — City Metro Smart-Card Fare Logic

Each task has `code.cpp`, `output.txt`, and `screenshot.png` (captured/rendered console output).

## Build and run
Use a C++17 compiler:
```bash
g++ -std=c++17 -Wall -Wextra code.cpp -o program
./program
```
On Windows, run `program.exe` instead. Tasks 1–12 correspond to the assignment PDF. Review and personalize the analysis, test cases, and evidence before submitting; Task 8 expects interactive input.
